# AurumPulse XAUUSD v6.49 — Integration Adapter

## Status
Integration scaffold only. v6.48 baseline on `main` is not modified.

## Purpose
Define the host-EA adapter contract for `EA/AurumPulse_v6.49_ExecutionEngine.mqh`.

## Host responsibilities
1. Evaluate/cache all custom indicators once per newly closed bar.
2. Populate `AP49_MarketContext` from the cached values.
3. Call `AP49_BuildPlan()` for BUY and SELL candidates.
4. Validate broker stop/freeze levels before any order operation.
5. Translate `AP49_ENTRY_ROUTE` into the existing broker execution layer.
6. Record candidate/placed/filled/expired/cancelled/error reason codes.
7. Run smart trailing and dynamic TP from the closed-bar context; reserve tick processing for emergency protection only.

## Safety rules
- Never modify `main` during integration.
- Never recalculate custom indicators inside the tick fast path.
- Never loosen an installed stop loss.
- Never move TP against the favorable direction.
- Never submit a broker modification when normalized SL/TP is unchanged.
- Pending orders must be cancelled when their structural premise is invalidated.

## Required mapping

| Route | Intent |
|---|---|
| MARKET | Fresh aligned momentum; no chase |
| BUY_LIMIT | Downside exhaustion/support reversal |
| SELL_LIMIT | Upside exhaustion/resistance reversal |
| BUY_STOP | Confirmed bullish reversal/breakout |
| SELL_STOP | Confirmed bearish reversal/breakdown |
